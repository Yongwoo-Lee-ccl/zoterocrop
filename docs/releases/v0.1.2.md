This is the first repository release for Zotero 9.0.x on macOS. It crops common margins from PDF attachments and adds the result as a new attachment.

- Preserves the original PDF and applies the same CropBox to every output page
- Accepts margin values such as `10pt`, `10`, and `3mm`
- Connects the version, download URL, and SHA-256 hash through the repository's `updates.json`
- Passes 16 Python engine tests and 12 plugin bridge tests

**Beta limitation:** Full integration testing of installation, menu actions, attachment import, restarts, and automatic updates in Zotero has not yet been completed. The previous 0.1.1 package passed the installation preflight check in Zotero 9.0.6.

Install `zoterocrop-0.1.2.xpi` from the release assets. Python 3.10 or later and a PyMuPDF/Pillow environment must be configured separately. Follow the installation instructions in the repository README. Users of 0.1.0 or 0.1.1 must install this version manually.
