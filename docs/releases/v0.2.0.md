# Crop Margins 0.2.0 beta

ZoteroCrop / PDF Common Crop is now **Crop Margins**. This release supports Zotero 10.0.x, including 10.0.3, while retaining Zotero 9.0.x compatibility.

## New settings

Open **Tools → Crop Margins: Settings…** or **Zotero Settings → Crop Margins**.

| Setting | Default |
| --- | --- |
| Preserve existing annotations | Off |
| Remove the original PDF after success | Off |
| Crop the vertical arXiv identifier | On |

The first two settings are independent. Preservation copies highlights, underlines, notes, text, image, and ink annotations, together with their comments, tags, colors, page labels, and displayed authorship. The attachment note is also copied. The crop includes visible annotation bounds and preserves original PDF coordinates and rotations, keeping copied annotations aligned.

Original removal moves the source attachment to **Zotero Trash** after the output and requested annotation copies are saved successfully. It never permanently deletes the source. Annotation copying and trashing share a database transaction; failures retain the original. External linked files remain on disk. Existing annotation links in other notes are not rewritten.

The arXiv option recognizes an isolated vertical identifier in the first page’s left margin and excludes it from margin measurement. It hides the identifier by cropping, without deleting the PDF’s underlying text. Other content and preserved annotations take priority; unsafe cases are retained with a warning. Scanned stamps are not detected.

## Validation

- 28 Python engine tests passed, covering rotations, CropBox offsets, embedded annotations, marginal notes, ink, rotated text, two-page highlights, and arXiv detection/opt-out safeguards.
- 23 bridge tests passed, including all toggle combinations, independent arXiv control, source changes during processing, and copy/trash failure rollback.
- Installed the final XPI in Zotero 10.0.3 on macOS and checked native Python execution, real attachment import, all four preservation/removal combinations, all six annotation types and their properties, unchanged source bytes, and plugin disable/re-enable.
- Inspected a real 15-page arXiv PDF before/after cropping: the side identifier was hidden; all page content streams, MediaBoxes, and rotations stayed unchanged; output display sizes were uniform.
- A full application restart, Zotero 9 runtime behavior, and automatic update delivery have not been tested end to end.

Install `crop-margins-0.2.0.xpi`. The internal plugin ID and update URL are unchanged, so existing installations retain their identity and settings. Python 3.10+ with PyMuPDF and Pillow is still required; see the README.
